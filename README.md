# LayerForge AI（開発中）

LayerForge AIは、AI、クラウド、業務自動化を組み合わせたSaaS設計・開発プロジェクトの公開ポートフォリオ版です。

## Public Portfolio Edition

このリポジトリは、転職活動および技術ポートフォリオのために作成したサニタイズ済み公開版です。実際の開発用リポジトリ、商用設計、認証情報、顧客データ、検証Dataset、内部Evidence、非公開機能は含まれていません。

This repository is a sanitized public portfolio edition. The private development and commercial repository is not published.

## Status

In Development

## Included

- Public-safe Next.js application structure
- Fully local mock-data demonstration
- A browser-only mock analysis flow (no upload or backend connection)
- Setup documentation and validation commands

## Not Included

- Production credentials
- Customer data
- Proprietary datasets
- Private commercial implementation
- Private project records
- Private commercial modules

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Select a supported file type to exercise the mock-only interface; the file remains in the browser and is never transmitted.

## Validation

```bash
npm run lint
npm run build
```
